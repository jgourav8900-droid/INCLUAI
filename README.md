# INCLUAI — Intelligent Workplace Platform

Welcome to **INCLUAI** (Inclusion + AI), developed by **Gourav** (CSE AIML).

A high-end Dribbble & Midjourney motion UI/UX design showcase uniting workplace intelligence, predictive growth analytics, voice-enabled AI Copilot, Tone Rewriter with Jargon Buster, Smart Message Replier, Automated Leave Portal, and ADHD Zen Focus Mode.

## 🚀 Key Features
- ✨ **Dribbble Trending Motion UI Showcase:** Obsidian dark mode, floating interactive cards, and live SVG spline growth curves.
- ⚡ **1-Click Demo Fast Pass:** Instant frictionless access for Gourav (AIML), Priya (HR Lead), and Admin.
- 📊 **Main Workspace Dashboard:** Real-time team velocity spline telemetry, 4 glassmorphic metric cards, and quick actions.
- 🤖 **Voice-Enabled AI Copilot:** Speech-to-text recognition, audio equalizer readout, and grounded handbook RAG.
- ✍️ **Smart Tone Rewriter & Jargon Buster:** Converts raw thoughts and informal Hindi/Hinglish into empathetic corporate emails.
- 💬 **AI Smart Message Replier:** Analyzes tricky workplace messages and drafts 3 intelligent options (Agree, Boundary, Clarify).
- 🏖️ **Automated Leave & Absence Manager:** Dynamic PTO/Sick/Casual balance deductions and approval workflow.
- 🧘 **ADHD Zen Focus Mode:** Distraction-free Pomodoro session with gentle rain audio synthesis.
- 🌐 **Dynamic 3-Way Translation:** Instant toggle between English, Hinglish, and Hindi.
- 🌓 **WCAG AAA Compliance:** High contrast mode, font scaling, and neurodiversity accommodations.

## 📁 File Structure
- `index.html`: Complete motion landing showcase & main enterprise dashboard
- `style.css`: Obsidian glassmorphism design system with neon gradients and keyframe animations
- `script.js`: Audio visualizer, Web Speech API, dynamic translations, chart curve switcher, and backend gateway
- `server/server.js`: Node.js Express backend serving APIs and static secure context

## 🛠️ Built With
- Vanilla HTML5, CSS3, JavaScript (ES6+)
- Node.js + Express backend running on `http://localhost:5000`
- Web Speech API & Web Audio API
